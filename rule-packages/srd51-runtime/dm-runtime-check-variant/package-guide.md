# Finite DM check variant

The `dm_runtime_house_rules` version `4` extension is the fourth member of
the bundled check variant. The first three members are
`srd51_runtime=2`, `srd51_characters=2` and `srd51_magic=2`, in that order.

The variant uses Wisdom for Athletics, grants Gnomish in the custom artisan
background, and sets the DM's fixed bludgeoning damage to 3 HP. These are
project house rules. The ordinary check and vital-effect consumers interpret
the declared values. The other rules retain the finite application scope.
