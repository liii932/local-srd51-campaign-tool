# 规则组合与战役冻结

本版 SQLite 将准确成员、最终规则、条目和完整字段链冻结在独立战役工作库中。同版残留恢复重新核对工作库内的冻结材料。打开便携文件则按本版规则重新组配准确成员，逐项核对保存的冻结材料。
