# 短弓与规则怪物远程攻击

## 射击

在无遮挡的活动规则场景中，角色先用普通动作开始攻击序列，再选择双手持用的短弓与目标。主持端在装备管理中逐支取得箭并将弓装备到双手。已获准查看场景和目标的玩家可直接使用“射击”按钮。按钮列出双方间的距离与射程档位。骷髅由 DM 在怪物本人回合通过“武器攻击”选择短弓和目标，消耗一个普通动作。[战斗与回合](schema-2-combat.md)

每格五尺，斜向与正向相同。射程从射手格到目标格计算，正常和长射程的上限均包含在内。

| 标准短弓距离 | 结果 |
| --- | --- |
| 至 80 尺 | 正常射程 |
| 85 至 320 尺 | 长射程，攻击掷骰具有劣势 |
| 超过 320 尺 | 在取骰、使用箭或攻击次数前拒绝 |

只要射手五尺内有能看见射手、尚未失能的敌人，远程攻击便具有劣势，近身敌人可以是目标以外的参战者。平面规则场景当前采用彼此可见的假设。角色卡和场景的共享权限决定玩家能查看和选择的目标。玩家只能看到向本人揭示的参战者和格位。多个劣势仍只取两枚 d20 中较低者，有优势和劣势时两者相抵。[攻击修正](../references/srd-5.1/pages/page-094.md) · [远程攻击](../references/srd-5.1/pages/page-095.md)

角色短弓使用敏捷修正，取得对应武器熟练的角色在命中掷骰上加熟练加值。标准伤害为 1d6 穿刺加敏捷修正。重击加倍伤害骰，固定修正加一次。已实际取得精通重击的勇士使用原选骰的 19/20 门槛。骷髅短弓使用自身条目的 +4 命中和 1d6+2 穿刺。骷髅短剑可用于借机攻击，短弓只用于本人的普通武器攻击。[短弓](../references/srd-5.1/pages/page-066.md) · [骷髅](../references/srd-5.1/pages/page-346.md) · [精通重击](schema-2-improved-critical.md)

## 箭支、护盾术与重开

每支箭是角色实际携带的一件装备。发射时服务器从匹配的 `CARRIED` 实例中按 UUID 的规范顺序选一支，记录其身份，扣除该箭并记一次攻击序号。手位、目标、射程、剩余攻击次数和弹药全部通过预检才可发射。未命中也会用去一支箭。有限怪物远程动作直接读取冻结条目，怪物没有角色式箭袋。[弹药](../references/srd-5.1/pages/page-064.md) · [双手持用](../references/srd-5.1/pages/page-065.md) · [装备作者合同](schema-2-foundation-authoring.md)

角色扣箭子事件 `COMBAT_AMMUNITION_SPENT` 与战斗根事件、原始 d20、攻击进度和已产生的后果共同提交。如果护盾术暂停结算，已用箭、原格距、射程、近身条件与原选骰保存在同一动作流中。重开后接受护盾术或放弃，再继续原攻击。结算读取原选骰和最终 AC，已发射的箭不会因射手在嵌套反应中倒地落弓而重新发射。重复提交沿用原回执，事务失败会回滚该命令的全部后果。

玩家对已揭示怪物的已决攻击收据显示命中、实际伤害及是否击倒。主持端的射击记录另列原骰、选骰及目标最终 AC，可与怪物剩余 HP 对照。怪物精确 HP、AC 与隐藏参战者资料仅 DM 可见。[玩家参与](../design/v2/player-participation.md) · [实物规则包对照](../../rule-packages/srd51-runtime/scenarios/README.md#ranged-weapons)
