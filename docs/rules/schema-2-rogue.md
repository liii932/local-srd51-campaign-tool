# 游荡者的专精与灵巧动作

标准角色包支持单职业游荡者 1–2 级。一级生命值为 8 加体质修正，升级可选 5 或由服务器掷 d8，再加体质修正。职业授予敏捷与智力豁免、轻甲、简易武器、手弩、长剑、细剑、短剑及盗贼工具熟练。武器仍须有可执行的武器配置并实际持用。[游荡者职业表与熟练](../references/srd-5.1/pages/page-039.md)

## 创建与检定

主持人创建 `class.rogue` 时，`skillKeys` 从职业冻结集合中选四个不同技能。标准包提供特技、运动、欺瞒、洞悉、威吓、调查、察觉、表演、游说、巧手及隐匿。`expertiseKeys` 选择两个不同的已熟练技能，或一个已熟练技能及盗贼工具。服务端把键解析为当前战役的完整规则身份。一级特性 `feature.rogue_expertise` 使用 `CHOICE` 与 `SRD_2014_ROGUE_EXPERTISE_V1`。建卡命令与取得的特性共同保留所选目标，重开时重演建卡与成长。

在这两个等级，已选目标的熟练贡献为 +4，其他已熟练目标为 +2，未熟练目标为零。属性修正与优劣势照常计算。个人主动及被动、团队、对抗、战斗隐匿与观察均读取角色的实际选择。工具检定还须在手中备好对应工具。攻击和豁免使用各自的熟练来源。主持人与获准控制角色的玩家可在卡面查看专精和贡献。[检定合同](schema-2-character-foundations.md)

若组合另外固定授予某项技能，建卡表单会把它列入专精候选，四项职业技能须从其余可选技能中选取。

## 本人回合的附赠动作

正常升至二级时取得 `feature.rogue_cunning_action`，算法为 `SRD_2014_ROGUE_CUNNING_ACTION_V1`。在活动战斗本人符合行动条件时，以下三项共用一次附赠动作。

| 命令 | 结算 |
| --- | --- |
| `CUNNING_DASH` 疾走 | 增加当前速度等额的本回合移动量。已走距离保留，普通疾走也可在同一回合使用。 |
| `CUNNING_DISENGAGE` 撤离 | 本回合后续移动受撤离保护。 |
| `CUNNING_HIDE` 躲藏 | 在可躲藏的格位掷一次敏捷（隐匿），逐个对照观察者的被动察觉。 |

三项均由战斗入口扣费，校验当前回合、角色取得的特性、预算、待决响应与行动资格。玩家提交还须持有有效会话与该角色的控制权。保存并重开同版战役后，预算、撤离状态、已发生的观察结果与原骰随战斗恢复，玩家须重新获准。[灵巧动作原文](../references/srd-5.1/pages/page-040.md) · [逐观察者躲藏](schema-2-observation.md)
