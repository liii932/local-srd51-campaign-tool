# 躲藏、观察与掩护

## 主持人布置场景

在工作台的战斗面板选择规则场景和格位，设置“允许躲藏”“遮挡视线”和掩护等级。空场景、探索及活动战斗均可布置。将两个选项清空并选“无掩护”即可移除标记。每个场景容纳 128 个标记，待决行动结算后才能编辑。玩家选择躲藏、搜索、移动或攻击，服务器从战役的规则和当时的格位裁定结果。

视线从观察者格中心到目标格中心。经过标记格内部即生效，擦过格角不计。忽略起点格，计入终点格。半掩护和四分之三掩护分别给武器攻击目标的 AC 加 2 和 5，经过多个标记取最高一级。全掩护同时阻断视线和直接武器攻击。主持端和玩家端都从武器攻击选项中移除全掩护的瞄准格，清除掩护后重新评估。单独勾选“遮挡视线”可以遮住生物并保留向已知格位攻击的可能。这些标记不改变步行费用。[掩护规则](../references/srd-5.1/pages/page-096.md)

## 谁知道什么

开战时先结算 DM 指定的隐匿者，每名敌人用自己的被动察觉与其比较。开场平手时该敌人察觉威胁。察觉任意一个敌人即可正常参加首回合，其余隐藏者的位置仍按各自的观察关系显示。[遭遇开场](schema-2-combat.md#encounter-opening)

普通躲藏（`HIDE`）需要本人回合、一个普通动作和允许躲藏的所在格。一次敏捷（隐匿）检定分别对抗每个存活敌人的被动感知（察觉）。结果高于某一观察者的被动值便对其隐藏。普通搜索（`SEARCH`）花一个普通动作，搜索者的一次感知（察觉）检定分别对抗仍对其躲藏的敌人的原隐匿总值。超过原值即可发现该敌人的位置。平手保留双方此前的观察关系。角色使用本人的属性、技能熟练与适用劣势，怪物使用冻结属性块中的对应数值。[躲藏与被动察觉](../references/srd-5.1/pages/page-081.md)

同一个生物可以被甲看见，却只在乙的地图留下最后已知格位。未曾发现它的观察者没有位置记录。每一步移动及每次改变标记都会重新判断相关视线。隐藏者离开允许躲藏的格子且进入观察者视线时，该观察者看见它。主动发现或听到攻击暴露的位置后，如视线仍受阻，观察者得到新格位但仍看不见对方。

规则场景及其中的怪物分别由 DM 共享。玩家页面再按每个受控角色的观察关系显示可见位置或“最后已知”。玩家的攻击距离、移动候选和借机提示均使用实际采取行动的角色视角。怪物精确 HP、AC、其他人的隐匿检定和完整观察记录只在主持端显示。[玩家视图与收据](../design/v2/player-participation.md)

## 攻击与反应

攻击者看不见目标会有劣势，目标看不见攻击者会给攻击者优势，与其他优势和劣势按普通规则抵消。目标当前不可见且有已知位置时，攻击瞄准该格。若目标已离开，仍花费该次攻击及适用箭支，结果为未命中。全掩护在取骰及付费前阻止攻击。隐藏者发动武器攻击便暴露所在格，命中和未命中都会更新各观察者对该攻击者的记录。[看不见的攻击者与目标](../references/srd-5.1/pages/page-094.md) · [短弓与弹药](schema-2-ranged-attacks.md)

借机攻击要求反应者在跨格前看得见离开触及的敌人。闪避对武器攻击的影响、远程攻击的近身劣势、预备动作的可感知触发和反制的施法见证同样按各自观察者判定。护盾术暂停后沿用攻击发起时的视线、掩护、瞄准格和原选骰重判。范围效果与敏捷豁免使用各自的效果合同。[借机攻击](../references/srd-5.1/pages/page-095.md) · [施法与反应](schema-2-spells.md)

## 附赠躲藏与保存

取得[灵巧动作](schema-2-rogue.md)的游荡者可用 `CUNNING_HIDE` 花一次附赠动作躲藏。仍需在可躲藏格掷一次真实隐匿检定，按观察者分别判定。角色的隐匿、被动察觉与搜索都会应用对应技能的专精。

标准魔法包的地精使用自己的弯刀、短弓、隐匿 +6 和被动察觉 9。其 `nimble_escape` 条目授予灵巧逃脱（Nimble Escape）。地精在本人回合可以花一个附赠动作合法躲藏（`NIMBLE_HIDE`）或撤离（`NIMBLE_DISENGAGE`）。付过一次后该回合无法再用另一项，普通动作可以留给攻击。[地精属性块](../references/srd-5.1/pages/page-315.md) · [独立作者场景](../../rule-packages/srd51-runtime/scenarios/README.md#observer-hiding)

同版完整文件保存格位标记、有方向的观察关系、最后已知位置、检定原骰和对抗结果。它们与动作花费、攻击及待决反应在同一事务提交。保存、结束战役并打开文件后，玩家经重新批准可从该角色原有的视角继续。已接受的请求重试沿用原收据。[运行与浏览器验收](../testing.md#observer-hiding-verification)
