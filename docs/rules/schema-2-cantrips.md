# 职业已知戏法与战斗施放

一级单职业法师和生命领域牧师建卡时从自己的四个职业选项中选三个。法师四级时再学一个。角色单独保存每个戏法的准确身份、来源职业、职业戏法配置和取得时的职业等级。角色卡区分可施放和仅记录的已知戏法。

| 职业 | 可在战斗中施放 | 可学并记录 |
| --- | --- | --- |
| Wizard | Fire Bolt（火焰箭） | Light、Mage Hand、Prestidigitation |
| Cleric | Sacred Flame（圣火术） | Guidance、Light、Thaumaturgy |

建卡表单提供已选好的职业模板，DM 可在提交前更换。服务端用战役冻结的 `character.class_cantrips` 配置、`cantrips` 成员和职业名额校验这次选择。两个执行法术的 `cantrip_profile` 保存射程、伤害骰面数、伤害类型、按角色总等级增加一枚骰的门槛，以及是否忽略豁免掩护加值。法术书、普通准备和生命领域始终准备各自保留原事实。[施法作者合同](schema-2-spell-authoring.md)

## 本人回合的普通动作

两项戏法均需 V/S、至少一只可用手和一个合法生物目标。主持端的「施放已知戏法」和玩家的行动候选使用同一服务端预检。玩家还须控制施法者，取得对场景及目标的访问权。施放声明支付一次普通动作，环位为 0。即使所有法术位耗尽也可使用。法术位、准备名额、箭支和攻击动作的击数均不消耗。

| 法术 | 服务端结算 |
| --- | --- |
| Fire Bolt | 120 尺内对一个生物作远程法术攻击，使用 INT 和熟练加值。命中造成 1d10 火焰伤害，角色总等级达到 5 后为 2d10。重击再加倍伤害骰。近身敌人、观察、掩护、Bless、Shield 与目标的伤害防御沿用各自规则。对最后已知格盲射时保留瞄准格。空格判定未命中。 |
| Sacred Flame | 60 尺内选择当前能看见的生物，依牧师的 WIS 计算 DC。目标以真实敏捷豁免对抗，成功无伤，失败造成 1d8 光耀伤害。半掩护和四分之三掩护均不提供这次豁免加值。完全掩护阻断选择。 |

这两个动作接入当前战斗的施法、反制和专注流程。施法者中途被反制仍保留已付动作。当前执行范围限本人战斗回合的生物目标。规则出处见 [Fire Bolt，SRD p.144](../references/srd-5.1/pages/page-144.md) 和 [Sacred Flame，SRD p.176](../references/srd-5.1/pages/page-176.md)。

## 结果与文件

DM 的战斗历史保存施法、原骰、伤害类型与实际伤害。玩家的本人结果给出命中或豁免结果、实际伤害和是否击倒。怪物的精确 HP、AC 和完整审计仅供 DM 查询。声明时尚有待决反应，原收据保留当时的等待状态。待结果确定，原施法玩家可在角色卡查看。

SAVE、END 和 OPEN 保留角色取得记录、已支付的动作、原骰、目标后果和未决反应。新运行中玩家经重新批准并取得控制后，服务端依恢复的观察关系、共享范围和回合状态重新生成合法候选。[玩家参与](../design/v2/player-participation.md) · [验收方法](../testing.md#known-cantrips-verification)
