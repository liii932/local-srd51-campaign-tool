# 近战控制：擒抱、推撞与挣脱

## 在工作台跑一回合

在焦点规则场景中安排两名相邻的规则角色，进入战斗。让一名已取得 Extra Attack 的五级战士先行动。

1. 开始本人攻击动作，选择对手和用于擒抱的空手。此时锁定当前一击，等待对手选择力量（运动）或敏捷（杂技）。主持人可代表目标选择，控制目标的玩家也可提交其防守候选。
2. 服务端先结算抓者的力量（运动），再结算防守方选定的技能。只有抓者胜出才建立关系。合法对抗完成即使用一击。战士还可用第二击攻击、推倒、推开或擒抱合法目标。
3. 想让对手倒地，选择推倒，再由对手选防守技能。推倒成功后姿态立即生效。若改选推开，目标沿双方连线向外移动一个五尺格。越出触及时相应擒抱随即解除。
4. 拖带时提交抓者和一名受擒者的配对路线。每一段的双方终点都须相邻且互不重叠，两条轨迹不能互换或交叉。抓者主动离开威胁区域时，在离开前处理借机攻击。被拖者保留本人的移动余额，强制位移本身不会招致借机攻击。双方实际入格都保留进入事实。若反应使抓者失能，或在停点免费释放，已走路段和已付花费保留，余下拖带停止。
5. 受擒者回合中可花一个动作，选择运动或杂技，对抗抓者的力量（运动）。只有挣脱者胜出才结束指定关系。抓者也可免费释放指定目标。关系结束释放对应手位，倒地的目标仍需自行起身。

擒抱和推撞均使用本人攻击动作的一击。借机攻击与 Ready 攻击维持各自的反应授权。若已准备的响应会由此次替代攻击完成或推开入格触发，当前战斗消费者在接纳尝试前拒绝该分支。擒抱者失能、目标死亡或双方分离超出手臂触及时，服务端结束对应关系。受擒者速度为零，即使尚有剩余移动或处于疾走状态，也无法自行移动或起身。降到零速时失去当前闪避收益，本回合解除擒抱也不会恢复先前的闪避。[SRD 第 95 页](../references/srd-5.1/pages/page-095.md) · [第 96 页](../references/srd-5.1/pages/page-096.md) · [Grappled](../references/srd-5.1/pages/page-358.md)

## 数值与支持范围

| 项目 | 战役解释 |
|---|---|
| 对抗门槛 | 从冻结的 `adventure.check.contest_minimum_winning_margin` 读取，作者可配置整数 1–3。标准为 1，随附检定变体为 2。两边均按该门槛裁定。16 对 15 在标准包建立擒抱，在变体保持原状。相同总值总是保持现状。 |
| 双方骰值 | 复用真实属性、实际技能熟练、装备约束和普通检定选骰。攻击方固定力量（运动），防守者二选一。挣脱时由受擒者选技能。推撞与擒抱都不掷武器攻击骰或伤害骰。 |
| 攻击次数 | 本人 Attack 的标准额度为一。五至六级单职业战士取得已启用的 Extra Attack 后为二。具体来源见[额外攻击](schema-2-extra-attack.md)。 |
| 触及与体型 | 本版处理活动战斗中能检定的人类、矮人（含山丘矮人）规则角色。均为中型、各占一个五尺格，身体触及五尺。禁止对超过抓者或推撞者一个体型等级的目标尝试。怪物属性块、自由卡、多格体型、特殊肢体及武器延伸触及在此入口范围之外。 |
| 移动 | 包定义基础步速和重甲规则。抓者拖带时有效速度减半，目标小至少两个体型等级时免减半。在当前角色范围内均适用减半。先将本回合的速度和疾走额度合计减半，再减去本回合已经花掉的移动。步行按实际格距扣费，爬行仍为双倍。直立、尚未移动、没有疾走的 30 尺角色可拖带三个五尺步段。格距、身体触及、推开五尺和减半规则由应用战斗算法固定。 |
| 关系与姿态 | 每条关系记录抓者、目标、占用手、触及和建立它的对抗。不同空手可分别抓住不同目标，每条关系单独解除。受擒、倒地和健康分别有自己的解除条件。Grappler 专长的压制与攻击优势另有机制边界。 |

## 文件与重试

离开战斗模式前须先结束所有活动擒抱。工作台的保存和结束战役文件可在关系活动时执行。等待防守、首击已完成和反应暂停都是可保存点。打开完整文件后，工作台由原场景的待选技能、攻击次数、双方位置、已走前缀、待处理反应和活动关系列出可继续的操作。记录保留双方原骰、所选骰、属性与熟练贡献、总值和裁定。服务端核对战役修订、场景版本及对应序列或叶子，重复已接受请求返回原收据。一次拖带更新共用 SQLite 事务，配对位置、已花移动、关系和根历史共同提交或回滚。[完整文件](../design/v2/save-and-recovery.md) · [定向验证](../testing.md#melee-control-verification)
