# 规则参考原文

查询 SRD 5.1 原文时，优先使用[本地主题索引与分页文本](srd-5.1/README.md)，
搜索后只读取相关页；跨页段落或表格连同相邻页读取。派生 Markdown 保留英文正文，
不进行规则摘要或翻译。引用标明原文页码和章节名。

表格、脚注或文字提取有歧义时，按页内链接核对[本地 PDF](srd-5.1.pdf)。
分页文本缺失或与 PDF 不一致时，先按[提取工具说明](../../tools/reference-docs/README.md)
从本地 PDF 重建；日常查询不需要联网或重新下载。只有本地 PDF 缺失/损坏，或任务明确
要求核对官方来源时，才访问官方在线源。

本地 PDF 是 D&D 5e 2014 的官方英文 System Reference Document 5.1（SRD 5.1），
取自[官方来源](https://media.dndbeyond.com/compendium-images/srd/5.1/SRD_CC_v5.1.pdf)。
文件原文未修改，保留 PDF 原有页码。

[NOTICE](../../NOTICE)。

采用边界仍由[冻结 v1 合同](../rules/srd-5.1.md)、[完整规则目标](../rules/srd-5.1-complete.md)
及相关设计、迁移与当前实现决定；原文覆盖不代表功能已实现或规则包已发布。
